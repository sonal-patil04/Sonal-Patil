### 🏠 SheStay – Girls Hostel / PG Management System

**SheStay** is a responsive front-end web application designed to help users explore, search, and book PG accommodation.

The project includes features such as room filtering, dynamic room details, booking functionality, user login and registration, contact forms, and responsive design.
